# Security policy

## Report a vulnerability

Do not open a public issue for a vulnerability.

Report it privately through GitHub:

1. Open the [Security tab](https://github.com/daniel-kindl/diffy/security) of this repository.
2. Select "Report a vulnerability".
3. Describe the problem, the affected version and the steps that show it.

The owner reads each report and answers in the report thread.

## Supported versions

Diffy has no release yet. After the first release, only the latest release gets security fixes.
